# Laundry App – Responsive Hero Section

##  Project Description

This project is a responsive laundry web application homepage created using **HTML and CSS**.

The main purpose of this task is to make the laundry app's Hero Section responsive so that it works properly on:

- Desktop
- Tablet
- Mobile devices

The layout uses **CSS Flexbox** and **Media Queries** to adjust the navigation bar, text, button, and laundry image according to the screen size.

---

##  Features

### Navigation Bar
- Laundry app logo
- Home link
- Services link
- About Us link
- Contact Us link
- Username button
- Navigation links are hidden on mobile devices
- Font sizes are reduced on tablet screens

### Hero Section
- Main heading
- Highlighted "Laundry Services!" text
- Description
- "Book a service today!" button
- Laundry image
- Responsive alignment using Flexbox

### Responsive Design
The website adapts to different screen sizes using CSS Media Queries.

#### Desktop
- Text and image appear side-by-side.
- Full navigation menu is displayed.

#### Tablet
- Text and image remain side-by-side.
- Font sizes and image sizes are reduced.

#### Mobile
- Navigation links are hidden.
- Only the logo and username button are displayed.
- Hero content changes to a column layout.
- Image appears below the text and button.
